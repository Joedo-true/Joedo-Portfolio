# Joedo.dev — портфолио фронтенд-разработчика

Премиальный одностраничный лендинг-портфолио на **React + TypeScript + Tailwind CSS + Framer Motion**.
Идеальный скролл-лендинг с тёмной/светлой темой, живыми интерактивными макетами проектов и плавными
анимациями появления блоков.

![Stack](https://img.shields.io/badge/React-18-61DAFB) ![TS](https://img.shields.io/badge/TypeScript-5-3178C6) ![Tailwind](https://img.shields.io/badge/Tailwind-3-2DD4BF) ![Vite](https://img.shields.io/badge/Vite-5-646CFF)

## ✨ Возможности

- **Шапка** — липкая (sticky) с эффектом матового стекла при скролле, текстовый лого `[Joedo].dev`
  с неоновой подсветкой, якорная навигация, переключатель тем и кнопка «Быстрая связь» с заливкой рамки.
- **Hero** — тег доступности с пульсирующим индикатором, продающий заголовок, две CTA-кнопки и
  **интерактивная сцена**: сетка точек и геометрические фигуры мягко следуют за курсором (параллакс
  на motion-value — без нагрузки на процессор).
- **Проекты** — 3 бизнес-кейса (AutuDash, Sollers Shop, FlexiCalc) в чередующейся раскладке.
  Каждый макет — **живой интерактивный интерфейс**:
  - AutuDash — дашборд на **Recharts** с кликабельными графиками и таблицей заказов;
  - Sollers Shop — каталог с фильтром по цене (слайдер), категориями и живой корзиной;
  - FlexiCalc — многошаговый калькулятор-квиз с расчётом стоимости на лету.
- **Стек** — плиточная сетка, сгруппированная по назначению (Core / UI-UX / Build & Deploy).
  Плитка при наведении окрашивается в фирменный цвет технологии.
- **Процесс** — горизонтальная timeline из 4 шагов (адаптируется в вертикальную на мобильных).
- **Контакты** — форма из 3 полей с градиентной подсветкой рамки при фокусе, «магнитная»
  кнопка отправки и быстрые ссылки в Telegram / Email.
- **Тёмная тема** — глубокий графит `#0F172A` (не чистый чёрный); **светлая** — молочно-белая.
- **Адаптивность** — от маленького смартфона до широкого десктопа, без горизонтального скролла.
- Уважается системная настройка `prefers-reduced-motion`.

## 🚀 Запуск

### Вариант 1 — просто открыть в браузере (без установки)

В репозитории уже лежит готовый **self-contained файл** —
[`standalone/index.html`](standalone/index.html). Весь сайт (React, стили, графики)
встроен в один HTML-файл. Ничего ставить и собирать не нужно:

> **Скачайте `standalone/index.html` и откройте его двойным кликом в браузере.**

Работает по протоколу `file://`, без сервера. Единственное, что подгружается из
сети, — красивый шрифт Inter (при отсутствии интернета подставится системный).

Пересобрать этот файл после правок в коде:

```bash
npm install
npm run build:standalone   # → standalone/index.html
```

### Вариант 2 — полноценная разработка (Vite)

```bash
npm install
npm run dev      # локальная разработка → http://localhost:5173
npm run build    # прод-сборка в dist/ (для Vercel/Netlify)
npm run preview  # предпросмотр прод-сборки
```

> ⚠️ Файл `index.html` в корне — это точка входа для Vite, его нельзя открыть
> напрямую двойным кликом (он подключает исходники через сборщик). Для открытия
> «как есть» используйте `standalone/index.html`.

## ⚙️ Настройка под себя

Все контакты и мета-данные вынесены в один файл — **`src/data/site.ts`**
(Telegram, Email, GitHub, пункты навигации). Контент проектов — в `src/data/projects.ts`,
навыки — в `src/data/skills.ts`, шаги процесса — в `src/data/workflow.ts`.

Форма отправки собирает письмо и открывает почтовый клиент (`mailto:`) — бэкенд не требуется.
Для реальной отправки подключите свой обработчик (Formspree, Telegram Bot API, серверлесс-функцию)
в `src/components/Contact.tsx`.

## 🌐 Деплой

Проект — статический, разворачивается на **Vercel** или **Netlify** из коробки:
команда сборки `npm run build`, каталог публикации `dist`.
