# Планета

Гекс-планета в WebGL: экран загрузки с полётом сквозь звёзды, «резкая остановка» —
и планета из двух с половиной тысяч шестиугольников. Материки, песчаные берега,
реки и озёра, три постройки на поверхности. По клику камера подходит ближе, и
планету можно крутить мышью.

`React 18` · `TypeScript 5` · `Vite 5` · `three r169` · `@react-three/fiber` · `GSAP` · `Zustand`

## Что внутри

**Экран загрузки.** Белые полосы разлетаются из центра и удлиняются к краю — так
выглядят звёзды, размазанные скоростью. В центре чёрный круг с растворяющимся
краем: он закрывает точку схода. Длительность определяется реальной готовностью
планеты — прогресс приходит из сборки геометрии, а не из таймера. Нижняя граница
(`loader.minDurationMs`) нужна только чтобы полёт успел прочитаться.

**Резкая остановка.** Полосы тормозят в точки, поле пустеет изнутри наружу, за
ними проступают настоящие звёзды, а планета подходит, проскакивает свой размер и
оседает назад.

**Планета.** Многогранник Голдберга — двойственный геодезической сфере: 2562
плитки, около 116 по окружности. Двенадцать из них пятиугольники: замостить сферу
одними шестиугольниками нельзя, это теорема Эйлера, а не упрощение. Вся планета —
одна слитая сетка с цветом в вершинах, один вызов отрисовки.

**Ландшафт.** Детерминированный: зависит только от зерна в конфиге, при каждом
открытии сайта одинаковый. Крупная форма с искажением области даёт материки с
изрезанным берегом; уровень моря берётся по доле воды, а не константой; лужи в
пару плиток засыпаются, одинокие плитки в океане затапливаются; реки текут вниз
по склону от вершин к морю, переливаясь через мелкие впадины. Пляж — только
пологая суша у воды, иначе песком зарастает треть планеты.

**Рельеф и жизнь.** Плитки подняты по высоте — рельеф ступенчатый, как и
положено гекс-миру. Выше границы леса трава сходит на камень, ещё выше ложится
снег. Леса растут пятнами по отдельному полю шума (равномерная посадка читается
газоном, а не лесом), в низинах между ёлками стоят круглые деревья, на камнях
лежат валуны. Всё это — инстансинг: тысячи деревьев рисуются за пять вызовов.
Над планетой идёт облачный слой, чуть быстрее её самой, и летают стаи; свет
кладёт настоящие тени — от гор на равнину, от деревьев на траву.

**Три постройки.** Рынок из семи лавок на подзоле, АЭС с градирней и паром на
бетонной площадке, обсерватория с телескопом и лабораторным корпусом. Общий язык:
коробки, цилиндры и конусы, плоское затенение, три материала на всё.

**Порталы.** У каждой постройки своя плитка-портал — не предмет на шестиугольнике,
а отдельный тип шестиугольника: вместо ровного верха у него каменная рамка и
утопленный колодец, а на дне колодца крутится воронка. Спираль рисуется шейдером
в полярных координатах: угол уводит тем сильнее, чем дальше от центра, и ровные
волокна шума разъезжаются в вихрь. Под указателем воронка разгорается.

Красный в середине рынка, зелёный у станции, синий у обсерватории; по клику
открывается соответствующий сайт. Адреса лежат в `links` в `src/config.ts`.
Постройка при этом доворачивается свободной стороной к своему порталу, чтобы он
не оказался под машинным залом.

## Запуск

```bash
npm install
npm run dev        # разработка → http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # предпросмотр прод-сборки
npm run lint       # проверка типов
```

Готовый self-contained файл лежит в репозитории:
[`standalone/index.html`](standalone/index.html) — весь сайт в одном HTML,
открывается двойным кликом без сервера. Пересобрать после правок:

```bash
npm run build:standalone   # → standalone/index.html
```

> Файл `index.html` в корне — точка входа для Vite, двойным кликом он не
> откроется. Для этого есть `standalone/index.html`.

## Настройка

Все параметры собраны в **`src/config.ts`** и выставлены наружу двумя способами
сразу, потому что расширения для живой правки читают разное:

1. **CSS-переменные на `:root`** — `--loader-streak-count`, `--planet-water-fraction`
   и так далее. Имя получается из пути в объекте: `loader.streakCount` →
   `--loader-streak-count`.
2. **Глобальный объект `window.SITE_CONFIG`** — та же структура, обычные числа и
   строки.

Правка любой из двух поверхностей подхватывается на ходу, перезагружать страницу
не нужно: синхронизация двусторонняя, значения перечитываются пять раз в секунду.

Параметры, помеченные в `src/config.ts` как `rebuild`, задают саму геометрию
планеты — они применяются при следующей загрузке страницы, а не на лету.

Заметные ручки:

| Параметр | Что делает |
| --- | --- |
| `loader.streakCount`, `streakSpeed`, `flickerHz`, `flickerDepth` | плотность, скорость и мерцание полос |
| `loader.discRadius`, `discFeather` | чёрный круг в центре и мягкость его края |
| `camera.idleWidthFraction` | доля ширины окна под планету на главном экране |
| `camera.idleMaxHeightFraction` | предохранитель по высоте, см. ниже |
| `camera.zoomWidthFraction` | то же после приближения |
| `planet.waterFraction` | сколько планеты под водой; у Земли 0.71 |
| `planet.reliefHeight`, `rockLine`, `snowLine` | высота гор, границы камня и снега |
| `flora.treeDensity`, `treePerTile`, `forestScale` | густота лесов и размер массивов |
| `clouds.count`, `radius`, `driftSpeed` | облачный слой |
| `birds.flocks`, `perFlock` | стаи; 0 — пустое небо |
| `atmosphere.strength` | ореол вокруг диска; 0 — выключен |
| `light.keyIntensity`, `fillIntensity`, `rimIntensity` | свет звезды, подсветка ночной стороны, контровой |
| `planet.seed` | другое зерно — другой материк |
| `palette.*` | цвета плиток, растительности и построек |

**Про долю ширины.** Ширина считается по диаметру планеты, но есть потолок по
высоте окна: на широком мониторе диск, занимающий заданную долю ширины,
оказывается выше самого окна, и его срезало бы сверху и снизу. Поэтому рядом с
`camera.idleWidthFraction` стоит `camera.idleMaxHeightFraction` — берётся то из
двух, что даёт планету меньше. На телефоне обычно работает доля ширины, на
десктопе — потолок по высоте. Поставьте потолок 99, чтобы отключить его совсем.

**Вращение.** Вблизи планета крутится мышью без ограничений по обеим осям: её
можно перевернуть и докрутить до любой точки, включая полюса.

## Деплой

`.github/workflows/deploy.yml` собирает сайт и публикует на GitHub Pages при
каждом пуше в рабочую ветку. Один раз включите Pages: **Settings → Pages → Build
and deployment → Source → GitHub Actions**. Пути к ресурсам относительные
(`base: './'`), поэтому сайт работает и из подпапки.
